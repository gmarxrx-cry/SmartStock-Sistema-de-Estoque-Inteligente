📦 SmartStock - Sistema de Estoque Inteligente
🧠 Sobre o projeto

O SmartStock é um sistema simples de gerenciamento de usuários com login e cadastro, desenvolvido em Python com interface gráfica utilizando CustomTkinter e banco de dados SQLite.

O projeto está em evolução e será expandido para um sistema completo de estoque com funcionalidades de CRUD e previsões de demanda.

🚀 Funcionalidades atuais
Sistema de login de usuários
Cadastro de novos usuários
Validação de login com banco de dados SQLite
Interface gráfica com CustomTkinter
Estrutura organizada com main()
Separação de módulos (login, cadastro e banco de dados)
🛠️ Tecnologias utilizadas
Python 🐍
SQLite 🗄️
CustomTkinter 🎨
Git & GitHub 🌐
